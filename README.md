## 🎯 Overview · Proje Özeti

<table>
<tr>
<td width="50%" valign="top">

<h3>🇬🇧 English</h3>

**Sporinho ♥** is a warm, beginner-friendly **Progressive Web App (PWA)** crafted with love as a personal gym companion for **Zeynep Çiğdem**. Built with **React 19**, **TypeScript**, **Vite 6**, and **Tailwind CSS v4**, it removes first-day gym anxiety through clear visual form coaching and zero-friction workout tracking.

- **21 Curated Exercises** across **4 categories** (*Lower Body & Glutes: 9, Upper Body: 8, Core: 3, Cardio: 1*) and **5 equipment types**.
- **21 Custom Interactive SVG Animations** with phase scrubbing, `0.5x` slow-motion mode, breathing cues, and a front/back **13-muscle anatomy map**.
- **Flexible Weekly Planner** supporting **2, 3, 4, or 5 days/week** splits across **3 goal focuses** (*Balanced, Glute/Lower, Cardio & Tone*).
- **Live Workout Runner** with warmup/main/cooldown phases, per-set weight & rep logging, and a **Web Audio API** rest chime timer.
- **Offline-Ready & Private:** Custom Service Worker (`sw.js`) and 100% client-side `localStorage` persistence — no account or backend required.

</td>
<td width="50%" valign="top">

<h3>🇹🇷 Türkçe</h3>

**Sporinho ♥**, **Zeynep Çiğdem** için sevgiyle hazırlanmış, spora yeni başlayanların salondaki ilk gün heyecanını azaltan, sıcak tasarımlı kişisel bir **Progressive Web App (PWA)** spor rehberidir. **React 19**, **TypeScript**, **Vite 6** ve **Tailwind CSS v4** ile geliştirilmiştir.

- **21 Seçkin Egzersiz:** **4 kategori** (*Alt Vücut & Kalça: 9, Üst Vücut: 8, Core & Karın: 3, Kardiyo: 1*) ve **5 ekipman tipi** (*Makine, Dambıl, Kablo, Vücut Ağırlığı, Kardiyo*).
- **21 Özel İnteraktif SVG Animasyonu:** Hareket akış çubuğu, `0.5x` yavaşlatma, nefes yönlendirmeleri ve ön/arka **13 bölgeli kas haritası**.
- **Esnek Haftalık Planlayıcı:** Haftada **2, 3, 4 veya 5 gün** seçeneği ve **3 antrenman odağı** (*Dengeli, Alt Vücut & Kalça, Kondisyon & Enerji*).
- **Canlı Antrenman Modu:** Isınma → Ana Hareketler → Soğuma akışı, set/ağırlık kaydı ve **Web Audio API** destekli sesli dinlenme sayacı.
- **Çevrimdışı & Gizli:** Özel Service Worker (`sw.js`) ve tamamen tarayıcı içi `localStorage` kalıcılığı — üyelik veya sunucu gerekmez.

## 🚀 Getting Started · Kurulum ve Çalıştırma

### Prerequisites · Gereksinimler
- **Node.js** `18+` & **npm**

### Local Development · Yerel Kurulum

```bash
# 1. Clone the repository · Repoyu klonla
git clone https://github.com/yorukokan/sporinho.git
cd sporinho

# 2. Install dependencies · Bağımlılıkları yükle
npm install

# 3. Start the Vite dev server · Geliştirme sunucusunu başlat
npm run dev
```

### Production Build & Preview · Üretim Derlemesi ve Önizleme

```bash
# Type-check with TypeScript and build for production (tsc -b && vite build)
npm run build

# Preview the production bundle locally (registers /sw.js Service Worker)
npm run preview
```

### PWA & Vercel Deployment · PWA ve Vercel Dağıtımı
- **Service Worker (`public/sw.js`):** Automatically registered only in production builds (`import.meta.env.PROD`), caching core assets under `sporinho-v1` with a network-first, cache-fallback strategy for same-origin `GET` requests.
- **Vercel (`vercel.json`):** Configured with SPA fallback rewrites (`/(.*) → /index.html`) and `Cache-Control: public, max-age=0, must-revalidate` on `/sw.js` so users always receive fresh updates.
- **Mobile Installation:** Open [`sporinho.vercel.app`](https://sporinho.vercel.app) in **iOS Safari** (*Share → Add to Home Screen*) or **Android Chrome** (*Menu ⋮ → Install App*).
